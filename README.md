# eat

application for automatic tracking of participation in events

# Prerequisites

Java 21+, maven 3.9.9+, docker 27.4.0+

# RUN GUIDE

1 - git clone https://github.com/soda-javadev/eat.git

2 - mvn clean package

3 - docker-compose up

4 - java -jar ./target/eat-0.0.1.jar

5 - http://localhost:8080/swagger-ui/index.html#/
